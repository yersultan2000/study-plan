# Study Plan

A phone-first daily study app: Calc BC, AP Statistics, AP Macro, SAT, IELTS and olympiads.

Live: https://yersultan2000.github.io/study-plan/

- One task at a time, with timers, swipe to finish, and a 7-day preview
- Course trackers, error log, writing studio, formula sheets, vocabulary cards
- Works offline and installs as an app; progress is saved on the device (back up from Tools → Backup)
